# PatentFlow 方法设计与实现对应

本文件描述可运行设计，不声称已经优于baseline或已证明新颖性。数据统计在
reports/raw_audit、dataset_statistics、feasibility。旧窗口试运行在
reports/superseded_pre_window_pilot，不进入最终表。所有设计结论以正式
raw-annual-v2的训练期探针、验证集和最终三seed结果为准。

docs/feasibility_report.md 与 reports/data_analysis。时间窗口、组织识别和词典外
分类隔离是协议的一部分。组织筛选同时保留企业和机构，不能将所有节点称为公司。

All 视图的历史合作覆盖增益：CN为 .11934，95%区间[.10752,.13055]；
US为 .16292，[.14863,.17401]；IN为 .05706，[.03602,.07794]。
IN_B、IN_F的区间跨0，IN_C为正。行为profile聚类探针在各视图平均有增益，
但IN_B仅约 .003 NDCG，不能据此认定可学习社区模块必然有效。

快慢文本漂移与下一训练年新类别比例的Spearman相关为CN −.21491、IN −.18580、
US −.05583。因此数据不支持“文本漂移越大，新业务越多”的单调假设，须保留

探针仅使用训练目标期；内部探针共享训练期Word2Vec，属于观察性可行性分析。
模块的预测收益仍以三种子独立消融与验证集结果检验。当前主实现唯一入口为

## 符号与任务

u是组织，c是IPC分类，p是公开专利记录，t是公开日，Y_u^{y+1}是下一自然年
真实IPC集合。预测时只允许访问截至y年末的历史H_y；分类预测层级L∈{1,2,3}。
e=(u,c,p,t)是展开后的时间边，x_p∈R^100是标题+摘要向量，R_c∈R^100是固定
随机投影的类别身份向量。R独立于IPC文本，便于将时间结构与全局语义分开消融。

## 文本与全局层级语义

每个国家在其All训练期、筛选后记录上训练skip-gram Word2Vec：100维，window=5，
min_count=5，negative=5，epochs=5。分词最多512个token；中文jieba，英文正则。
该country-All预训练用于同国section视图，是公开的共享训练语料设置，不称为
严格仅section内的预训练。IPC描述不混入Word2Vec训练；验证/测试文本仅编码。

文档向量为SIF式加权均值：x_p=Σ_w q_w v_w/Σ_w q_w，q_w=a/(a+f_w)，a=.001；
f_w仅由训练词频估计。缺词时使用零向量并记录覆盖率，不生成缺失标题。

IPC静态向量a_c=normalize(mean_{j∈{c及其祖先}}Embed(description_j))。
祖先来自用户指定的section→class→subclass词典。只保存实际观测节点和其祖先；
词典外分类在原表保留，在主实验隔离。a_c是不可变buffer，动态时间更新不覆盖它。
它在每次IPC表征读出时重新注入：h_c=normalize(W_a a_c + .5 f_d(m_c))。
这是显式语义保留路径，但不能从公式直接断言嵌入绝不会趋同；需要相似度分布和
去锚点消融验证。去掉直接锚点与去掉全局层级解码是不同消融。

## 因果加权双时间尺度记忆

用快速τ_f=180天和缓慢τ_s=1095天两组充分统计，避免每条边执行GRU及反向展开。
每个节点存储分子S、权重质量Z和最后更新日。一次时间组更新：

S_v^τ(t)=2^{-Δt/τ}S_v^τ(t^-)+Σ_{e∈E_v(t)}w_e m_e，
Z_v^τ(t)=2^{-Δt/τ}Z_v^τ(t^-)+Σ_e w_e，M_v^τ(t)=S_v^τ(t)/max(Z_v^τ(t),ε)。

组织消息m_u=[x_p;R_c]，分类消息m_c=[x_p;M_{u,struct}^{slow}(t^-)]。
原专利基础权重w_p=1/(|org(p)|·|IPC(p)|)，降低多申请人、多标签膨胀。
额外变化权重w_e=w_p[1+β(1-cos(M_{u,struct}^{slow}(t^-),R_c))]，β默认1；
余弦裁剪[-1,1]，单边权重有界。β=0是去变化加权消融。
同一天所有消息读旧状态，再按节点scatter求和，保证输入顺序不改变数学结果。
float32求和有舍入差异，因此检验用容差，不声称位级完全相同。

两个尺度的均值、衰减质量与时距共同供解码器使用。均值自身的时间衰减会相消，
不能仅凭均值声称模型知道长期不活跃；质量和age特征承担这个信息。
语义与结构通道分别投影，静态IPC锚点不参与结构随机投影，消融可真正隔离输入。

代价是O(E·d)的一次特征重放及O(N·d)记忆；改变τ/β需要重新构建缓存。
神经参数在读出层训练，**没有声称所有消息/衰减参数均通过BPTT端到端学习**。
这是可解释的效率取舍；若效果不足，可增加可学习衰减或递归更新对照，但须实测。

## 历史合作与行为社区

合作只由同一历史记录的共同组织生成。最近三个合作方的历史向量聚合为z_coop。
无合作、合作方在当前section没有历史状态时mask=0，贡献严格为0。门控g_coop由
节点历史质量、age、快慢一致性、合作数等因果特征计算，不利用目标年合作关系。

行为社区借鉴IDGP的Fluxon路由思想，但不是其原版热度模型。将组织过去的结构
profile投影并与K个可学习prototype求余弦，取top3、softmax归一化。社区memory
由过去节点profile按路由权重求均值，采用index_add而非稠密one-hot矩阵。
每个epoch/年界刷新社区缓存；缓存统计不回传梯度，查询路由和prototype仍通过
预测loss得到梯度。应称为“带可学习路由的历史社区缓存”，不是完全端到端动态图
社区发现算法，也不应仅凭可视化宣称它恢复了现实中的真实产业社区。

## 融合与优化

三个基础分数为文本动态语义、结构身份、全局层级语义匹配。融合权重由8维历史
可靠性特征的softmax得到。额外加上带sigmoid门控的合作、社区分数，以及16维
因果频次/近期变化特征的MLP residual。频次分支需单独消融，防止将频次收益
错误归因给语义或社区。

L=L_weighted-BCE + λ_rank L_listwise + λ_align L_geometry。
BCE处理空/非空下一年集合，类别pos_weight只按训练标签计算并裁剪[1,30]。
Listwise项对非空集合的正类归一化分布与全候选log-softmax计算交叉熵。
Geometry项最小化动态IPC表征余弦矩阵与固定锚点余弦矩阵的MSE，保留语义关系
差异，不把每个类别都拉到同一个公共祖先。默认λ_rank=.5、λ_align=.1；均需验证
选择及敏感性分析。主指标计算使用统一metrics.py，与loss不是同一个量。

## 必须完成的验证

- 原始数据筛选瀑布、时间覆盖、degree长尾、候选/OOV和空目标分组。
- 快/慢记忆、β、语义输入、结构memory、hierarchy decoder、直接anchor、
  alignment、合作、社区、repeat分支逐项及组合消融。
- τ_f、τ_s、β、community数、temperature、hidden dim、dropout、loss权重、
  learning rate敏感性。三个seed、统一验证预算，不按测试选最佳配置。
- 真实baseline适配完成，测参数量、训练/推理/预处理耗时、峰值CPU/GPU内存。
- 最佳epoch固定权重重放年份向量；跨年投影必须共用PCA/UMAP变换，不能将
  每年独立t-SNE图的坐标误读为位移。case选择依据公开的趋势变更规则，保留候选。
